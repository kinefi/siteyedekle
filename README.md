# siteyedekle

`siteyedekle`, Indexhibit ve dinamik web sitelerini tarayıcı üzerinden tamamen statik hale getirip HTML, CSS, JS ve medya dosyalarıyla birlikte `.zip` olarak indirmenizi sağlayan web tabanlı bir klonlama aracıdır.

## Özellikler

- **Kurulum Gerektirmez:** Node.js, Python veya sunucu ortamı kurmadan doğrudan tarayıcı üzerinden çalışır.
- **Modüler Yapı:** Tüm stiller ve betikler `assets/` dizininde düzenli olarak tutulur.
- **Statik Dönüştürme:** AJAX/JavaScript kaynaklı içerik ve görselleri tespit ederek yerel kullanıma uygun ZIP paketi sunar.

## Dosya Yapısı

```text
siteyedekle/
├── index.html
├── assets/
│   ├── css/
│   │   └── style.css
│   └── js/
│       └── app.js
└── README.md
```
